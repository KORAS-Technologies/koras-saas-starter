# Postman Setup

This document is now a routing page only, kept so existing links do not
break. The step-by-step runbooks live in two separate documents, because
LOCAL and deployed DEV need different URLs, different identities, and
different token sources — see `docs/api/postman-standard.md`'s "Running the
Collection" section for why they are not combined.

Choose your environment:

1. **LOCAL** (your own machine) → `docs/api/postman-local-setup.md`
2. **Deployed DEV** → `docs/api/postman-dev-setup.md`

For the generation architecture and contribution rules (not a setup guide):
`docs/api/postman-standard.md`.
