# /ui-review

Review the specified UI or current frontend changes.

Target:

```text
$ARGUMENTS
```

Instructions:

1. Read `.claude/CLAUDE.md`, `koras-ui-design-system`, and `koras-accessibility`.
2. Apply installed frontend-design and web-design-guidelines skills when available.
3. Inspect the implemented UI in a real browser when possible.
4. Review visual hierarchy, spacing, typography, responsiveness, states, consistency, component reuse, accessibility, keyboard behavior, focus states, validation, and browser console errors.
5. Check loading, empty, success, error, disabled, and submission states where relevant.
6. Verify both desktop and mobile-width layouts.
7. Return concrete findings ordered by severity and include recommended fixes.
8. If asked to fix findings, keep edits scoped and rerun the browser review.
